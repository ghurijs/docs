## Start on the edge, grow without a rewrite

Ghuri gives you the shape of Django (settings, installed apps, models with managers,
migrations, `urls.ts`, class-based views, an admin, a REST framework) written in strict
TypeScript and built on [Hono](https://hono.dev) and [Drizzle](https://orm.drizzle.team).

A new project runs on **Cloudflare Workers with D1, R2 and KV**. That costs close to nothing
while you find out whether anyone wants what you are building. When you outgrow it, point
`DATABASES` at Postgres, run `ghuri migrate`, copy your data with `ghuri dumpdata` and
`ghuri loaddata`, and deploy the same code to Node on any VPS or container platform.

```ts title="src/blog/models.ts"
import { Model, CharField, TextField, DateTimeField, ForeignKey, CASCADE } from '@ghuri/orm'
import { User } from '@ghuri/auth'

export class Post extends Model({
  title: new CharField({ maxLength: 200 }),
  body: new TextField({ blank: true }),
  author: new ForeignKey(() => User, { onDelete: CASCADE, relatedName: 'posts' }),
  createdAt: new DateTimeField({ autoNowAdd: true }),
}) {
  static Meta = { ordering: ['-createdAt'] }
  toString() { return this.title }
}

const recent = await Post.objects
  .filter({ author__username: 'rifat', title__icontains: 'workers' })
  .selectRelated('author')
  .slice(0, 10)
```

## Quick start

<Steps>

1. Create a project. The default template targets Cloudflare Workers with D1.

   ```sh
   npm create ghuri@latest mysite
   cd mysite
   ```

2. Add an app and create the database tables.

   ```sh
   npx ghuri startapp blog
   npx ghuri makemigrations
   npx ghuri migrate
   ```

3. Create an admin user and start the development server.

   ```sh
   npx ghuri createsuperuser
   npm run dev
   ```

   Open `http://localhost:8787/admin/` and sign in.

</Steps>

## One project, two homes

The only lines that change when you leave Cloudflare are in `settings.ts` and the entry file.

<Tabs>
  <TabItem label="Cloudflare Workers">
  ```ts title="src/settings.ts"
  DATABASES: { default: d1('DB') },
  STORAGES: { default: r2('MEDIA') },
  CACHES: { default: kvCache('CACHE') },
  ```
  </TabItem>
  <TabItem label="Node + Postgres">
  ```ts title="src/settings.ts"
  DATABASES: { default: postgres({ url: env.DATABASE_URL }) },
  STORAGES: { default: s3({ endpoint, bucket, accessKeyId, secretAccessKey }) },
  CACHES: { default: memoryCache() },
  ```
  </TabItem>
</Tabs>
